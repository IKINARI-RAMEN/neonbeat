# NEONBEAT v1.1

ブラウザで遊べる4レーンのキーボード・タップ音ゲーです。

## 起動と遊び方

`index.html` をVS Codeで開き、Live Serverなどで表示してください。

- PC：D / F / J / Kキー
- スマートフォン・タブレット：画面下の4レーンをタップ
- Enter または PLAY：開始
- NORMAL / HARD / EASY：譜面の速度を変更
- 「曲・動画を選ぶ」：端末内の音声/動画ファイルから簡易譜面を作成

音声ファイルはブラウザ内で解析します。動画はPLAYボタンから一度最後まで再生して音声を解析し、解析完了後にPLAY VIDEOでゲームとして再生します。動画が長い場合、解析にも同じくらい時間がかかります。動画の音声コーデックや形式によっては、ブラウザが再生できず解析に失敗することがあります。

自動譜面は音量の立ち上がりを拾う簡易検出です。曲によってノーツ数やタイミングに差があります。
