# NEONBEAT

ブラウザで遊べる4レーンのキーボード音ゲーです。

## 起動方法

`index.html` をVS Codeで開き、Live Server拡張機能などでローカルサーバーとして表示してください。`index.html`を直接開いても多くのブラウザで遊べます。

- D / F / J / K：ノーツを叩く
- Enter または PLAY：開始
- NORMAL / HARD / EASY：譜面の速度を変更
- 「曲を選ぶ」：端末内の音声を読み込み、簡易的な音量変化検出でノーツを作成

## YouTube URLについて

URLを貼るだけでYouTube動画の音声を解析して譜面を作る機能は、この静的なブラウザアプリだけでは実現できません。YouTubeは埋め込み動画の音声を他サイトのJavaScriptが読み取ることを制限しており、単にURLや埋め込みプレーヤーを使っても解析できません。実用化するなら、権利上利用できる音源をユーザーが選択・アップロードする方式、または利用許諾済みの音楽データ/APIが必要です。

音声ファイルからの自動譜面は簡易検出です。音量の立ち上がりを拾う方式のため、曲によってノーツが多すぎたり少なすぎたりすることがあります。
